    About Riemann Explorer
    
      
    This is a visualisation. It does not explain why the proof works, and the zeta landscape does not show the proof's method.
    
      
    What you see
    
      
    Zeta landscape. Height is log|ζ(σ+it)|, colour is arg ζ, over σ ∈ [−1, 2], t ∈ [0, 100]. The critical strip 0 < σ < 1 is framed; the critical line σ = ½ glows. Markers sit at the first 200 nontrivial zeros. The Hardy Z(t) plot and counter are computed live in your browser.
    
      
    Proof galaxy. One star per module of the Lean 4 proof (Levent Alpöge, working with Claude, 20 Nov 2026). Colour = top-level library, size = log(lines). The layout groups directories by imports. Every module is in Main's import closure, so imports say little about logical dependency, and directory names do not describe contents.
