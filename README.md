# Riemann Explorer

A single-page WebGL piece in two connected worlds:

1. **The zeta landscape.** A 3D surface of the Riemann zeta function over σ ∈ [−1, 2], t ∈ [0, 100]. Height is log|ζ(σ+it)| and colour is arg ζ. The critical strip is framed, the critical line Re(s) = ½ glows, and the first 200 nontrivial zeros are marked. A Hardy Z(t) plot and a zero counter run live in the browser.
2. **The proof galaxy.** Every one of the 175,187 modules of the Lean 4 proof of the Riemann Hypothesis (Levent Alpöge, working with Claude, released 20 Nov 2026) as one star. You can zoom, search and click.

A 45-second **story mode** flies from the first world into the second. It renders frame by frame at 1080p/60 for video.

> **This visualises. It does not explain.** Nothing here shows why the proof works. The zeta landscape does not show the proof's method, and the galaxy layout groups directories by imports, which say little about logical dependency.

## Run it

```bash
pnpm install
```

```bash
pnpm pipeline
```

```bash
pnpm dev
```

Then open http://localhost:5196.

The data pipeline needs Python 3.11+ and `uv`. It sparse-clones the Lean source (~1.3 GB) into `.cache/` the first time. The ζ grid takes about 3.5 minutes on 10 cores. Set `REGRID=1` to recompute it.

| URL | What it does |
|---|---|
| `/` | Explore mode: zeta landscape. The galaxy streams in after the landscape is visible. |
| `/?world=galaxy` | Start in the proof galaxy. |
| `/?story=1` | Story mode in real time (for screen recording). |
| `/?story=1&hideui=1` | Story mode with only the film elements: captions, the story Z(t) panel and the Lean card. |
| `/?story=1&hideui=1&capture=1` | Fixed 1920×1080 canvas, no clock: `window.__renderFrame(t)` draws the frame at time t. |
| `&aspect=4x5` | 1080×1350 canvas for the feed version. |
| `&debug=1` | lil-gui panel (bloom, exposure, fog). Never shown in story mode. |
| `&q=low` | Half-resolution landscape mesh for weak GPUs. |

Keys in the landscape: `f` flies the critical line; `]` and `[` step through the zeros; `Esc` clears the focus.

## Capture the video

```bash
pnpm capture
```

```bash
pnpm capture:4x5
```

These write `out/riemann-explorer.mp4` (1920×1080) and `out/riemann-explorer-4x5.mp4` (1080×1350): 60 fps, 45 s, H.264, `-crf 16 -pix_fmt yuv420p`. The script starts its own Vite server and drives the installed Google Chrome (headless, Metal GPU) with Playwright. Time comes from the frame index, not the clock, so no frame can drop. PNG frames go to `out/frames/` and are deleted after encoding; add `--keep-frames` to keep them. `--only=8,20,38` renders stills to `out/preview/`. On an M1 Max the 2,700 frames take about 7 minutes, plus about a minute to encode.

Edit the script in [`src/story/timeline.ts`](src/story/timeline.ts): camera keys (Catmull-Rom with per-segment easing), captions and scalar tracks (fade, HUD, galaxy reveal, Lean card).

The last two need `pnpm dev` running.

- **Zeros** (`pipeline/zeros.py`): 649 zeros from `mpmath.zetazero` at dps 25, checked against Odlyzko's `zeros1` table. The largest error is 5.0e-10, the rounding floor of a 9-decimal table. γ₁, γ₂, γ₃, γ₁₀ and γ₁₀₀ are asserted.
- **TS maths** (`tests/zeta.test.ts`): Z(t) against `mpmath.siegelz` at 50 points in [10, 1000] (worst error 1.4e-8), θ(t) against `mpmath.siegeltheta`, the first 100 zeros from sign changes plus bisection (< 1e-6), N(100) = 29 and N(1000) = 649.
- **Grid**: ζ(½), ζ(2) and ζ(0) from the grid, and a local minimum of |ζ| at the sample nearest each of the 29 zeros below t = 100.
- **Visual alignment** (`scripts/visual-test.ts`): a top-down screenshot of the surface and a separate screenshot of the markers. Every marker is within 0.71 px of a surface minimum (tolerance 2 px).
- **Galaxy end to end** (`scripts/e2e-galaxy.ts`): a search for "MainConclusion" flies there, a click opens the right path, the GitHub link returns 200, and a pick takes about 2 ms.
- **Stats** (`tests/stats.test.ts`): every number on the stats card appears in `pipeline/REPORT.md`.
- **Story** (`tests/story.test.ts`): the timeline is deterministic, and the camera speed never changes by more than 3 units/s between consecutive 60 fps frames (no stop-start at keys).

## How the maths runs

- **Z(t) in the browser** ([`src/math/zeta.ts`](src/math/zeta.ts)). For t ≥ 100 it uses the Riemann–Siegel formula with corrections C0–C4. The coefficients are Taylor series generated by `pipeline/rs_coeffs.py` from Edwards §7.4. With C0–C4 the Riemann–Siegel error is 1.5e-5 at t = 10 and drops below 1e-6 only near t = 40, so for 10 ≤ t < 100 the code uses Euler–Maclaurin summation for ζ(½ + it) instead. Below t = 10 it reads the precomputed grid: there Z(t) = −|ζ(½ + it)|, because Z has no zero below γ₁ ≈ 14.13. θ(t) uses its asymptotic series.
- **Surface height.** The grid stores log|ζ| clamped to [−6, 4]. log|ζ| has a log singularity at every zero, which makes each zero a needle-thin pit that the walls hide. The mesh therefore uses ½·log(|ζ|² + ε²) with ε = 0.16. This equals log|ζ| away from the zeros and has its minima at exactly the same points. Colour and contours use the true log|ζ|.
- **Arg ζ** is interpolated in the fragment shader with phase unwrapping. Plain linear filtering would draw a false seam at the ±π cut.
- **Trivial zero.** ζ(−2) = 0 is drawn as an off-grid marker with a label, because the grid starts at σ = −1.

## License caveat

The Lean submission was published without a license. This repository and the deployed site ship **no `.lean` sources**. `public/data/` holds only derived metadata: module paths, line counts, import edges, declaration names and kinds, and statement snippets of at most three lines (whitespace collapsed, at most 182 characters). The side panel links to GitHub at the pinned commit for the full source.

## Performance

Measured on an M1 Max in Chrome, 1920×1080, with a full GPU sync every frame: landscape 4.7 ms, galaxy 3.4 ms per frame. On retina screens the backing store is capped at about 1080p pixel count. Total gzipped data is 18.9 MB (landscape 3.7 MB); the galaxy loads after the landscape is on screen, and per-module details load on click in 88 shards.
